# Portfolio and Print Shop

Language for Claire's portfolio photographs and their connected print offerings.

## Language

**Photograph**:
A portfolio entry with a stable identity. Its image, caption, and album can change without making it a different entry.

**Print edition**:
A specific image version of a photograph intended for printing. Replacing an image can create a new print edition without creating a new photograph.

**Print product**:
The shop offering for a photograph. It contains purchasable variants such as different sizes.

**Print file**:
The image supplied for manufacturing a print edition. It is not the same as a store preview or product mockup.

**Store preview**:
An image displayed to a buyer on a product page. Updating it does not establish that the corresponding print file changed.
